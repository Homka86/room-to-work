# Есть место

Сервис для поиска и бронирования рабочих мест в коворкингах университетского кампуса.

Сейчас реализован фронтенд MVP: интерактивная схема трёх этажей с 23 коворкингами, выбор даты и времени, список комнат, фильтр свободных мест и демонстрационные статусы доступности.

## Структура проекта

- `frontend/` — веб-интерфейс и тестовые данные;
- `TECH_PLAN.md` — краткая техническая инструкция;
- `IMPLEMENTATION_PLAN.md` — подробный план реализации MVP.

## Запуск фронтенда

```sh
cd frontend
pnpm install
pnpm dev
```

Проверки:

```sh
cd frontend
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/campus.test.mjs
pnpm build
```

Авторизация, база данных и настоящие бронирования будут добавлены на следующем этапе.
