# Есть место

Сервис для поиска и бронирования рабочих мест в коворкингах университетского кампуса.

Сейчас реализован фронтенд MVP: интерактивная схема трёх этажей с 23 коворкингами, выбор даты и времени, расписание на день для выбранной комнаты, количество участников, фильтр свободных мест, демонстрационные статусы доступности и локальный сценарий бронирования.

## Структура проекта

- `frontend/` — веб-интерфейс и тестовые данные;
- `TECH_PLAN.md` — краткая техническая инструкция;
- `IMPLEMENTATION_PLAN.md` — подробный план реализации MVP.

## Запуск фронтенда

```sh
cd frontend
pnpm install
pnpm dev
```

Проверки:

```sh
cd frontend
pnpm exec tsc --noEmit
pnpm build
```

Форма бронирования, роли ученика/преподавателя и рейтинг работают в демо-режиме и сохраняют данные только в `localStorage` браузера. Для ученика рейтинг начинается с 0: завершение брони даёт +1, одна отмена в месяц бесплатна, отмена более чем за 2 часа не даёт штрафа, последующие поздние отмены дают −2. При отрицательном рейтинге часть самых востребованных коворкингов становится недоступна, менее востребованные остаются доступны. В бронировании указывается фактическое количество участников в пределах вместимости комнаты. Один аккаунт может отвечать только за один коворкинг в одно время, а у коворкинга один ответственный на слот. Серверного API, авторизации и общей базы данных в текущем репозитории нет; их нужно подключить отдельно.
