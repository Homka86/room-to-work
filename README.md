# Есть место

Сервис для поиска и бронирования рабочих мест в коворкингах университетского кампуса.

Сейчас реализован фронтенд MVP: интерактивная схема трёх этажей с 23 коворкингами, выбор даты и времени, список комнат, фильтр свободных мест, демонстрационные статусы доступности и локальный сценарий бронирования.

## Структура проекта

- `frontend/` — веб-интерфейс и тестовые данные;
- `TECH_PLAN.md` — краткая техническая инструкция;
- `IMPLEMENTATION_PLAN.md` — подробный план реализации MVP.

## Запуск фронтенда

```sh
cd frontend
pnpm install
pnpm dev
```

Проверки:

```sh
cd frontend
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/campus.test.mjs
pnpm build
```

Форма бронирования и раздел «Мои бронирования» работают в демо-режиме и сохраняют данные только в `localStorage` браузера. Серверного API, авторизации и общей базы данных в исходниках из `Downloads` нет; их нужно подключить отдельно.
