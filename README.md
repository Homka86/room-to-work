# Есть место

Сервис для поиска и бронирования рабочих мест в коворкингах университетского кампуса.

Сейчас реализован фронтенд MVP: интерактивная схема трёх этажей с 23 коворкингами, выбор даты и времени, список комнат, фильтр свободных мест, демонстрационные статусы доступности и локальный сценарий бронирования.

## Структура проекта

- `frontend/` — веб-интерфейс и тестовые данные;
- `TECH_PLAN.md` — краткая техническая инструкция;
- `IMPLEMENTATION_PLAN.md` — подробный план реализации MVP.

## Запуск фронтенда

```sh
cd frontend
pnpm install
pnpm dev
```

Проверки:

```sh
cd frontend
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/campus.test.mjs
pnpm build
```

Форма бронирования, роли ученика/преподавателя и рейтинг работают в демо-режиме и сохраняют данные только в `localStorage` браузера. Для ученика рейтинг начинается с 0: завершение брони даёт +1, одна отмена в месяц бесплатна, отмена более чем за 2 часа не даёт штрафа, последующие поздние отмены дают −2. Рейтинг не блокирует аккаунт: при отрицательном значении закрыты пять самых востребованных коворкингов, менее востребованные остаются доступны. Каждая бронь добавляет коворкингу один скрытый балл на 30 дней. Один аккаунт может отвечать только за один коворкинг в одно время, а у коворкинга один ответственный на слот. Серверного API, авторизации и общей базы данных в текущем репозитории нет; их нужно подключить отдельно.
