# room-to-work

Сервис для поиска и бронирования рабочих мест в коворкингах.

## О проекте

"Есть место" помогает студенту быстро найти место для работы между занятиями и заранее забронировать его на нужную дату и время.

Пользователь выбирает коворкинг, дату и временной слот, видит доступные места и получает подтверждение бронирования.

## Возможности MVP

- каталог коворкингов;
- просмотр свободных рабочих мест;
- выбор даты и часового слота;
- бронирование места;
- просмотр и отмена своих бронирований;
- защита от двойного бронирования одного места на один слот.

## Пользовательский сценарий

1. Пользователь открывает сервис.
2. Выбирает коворкинг, дату и время.
3. Просматривает доступные места.
4. Выбирает место и подтверждает бронь.
5. Получает подтверждение и может управлять бронированием в личном разделе.

## Данные и ограничения демо

В демоверсии используются тестовые коворкинги и места, добавленные командой вручную. Доступность рассчитывается по бронированиям внутри прототипа.

Интеграции с реальными площадками, оплатой и внешними системами бронирования пока не входят в MVP. Если данные о доступности не загрузились, сервис показывает сообщение об ошибке и временно отключает бронирование.
