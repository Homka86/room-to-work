# Backend

Серверная часть сервиса бронирования находится в этой папке.

- `campus-service.ts` — сессии, бронирования, отмены, рейтинг и ограничения доступности.
- `database.ts` — подключение к D1/SQLite-хранилищу.
- `../frontend/db` и `../frontend/drizzle` — схема и миграции базы данных.

API подключается через `frontend/app/api/campus/route.ts`, а интерфейс остаётся в папке `frontend`.
