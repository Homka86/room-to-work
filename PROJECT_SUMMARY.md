# «Есть место»

«Есть место» — веб-сервис для поиска и бронирования учебных пространств в кампусе.

В кампусе три этажа и 23 помещения. Пользователь выбирает этаж, дату и время, видит состояние комнат на условной схеме и открывает подробности выбранного пространства: вместимость, назначение, оборудование и расписание на день.

После выбора даты и времени помещения получают цветовой статус:

- зелёный — свободно;
- жёлтый — займут в течение 30 минут;
- красный — занято.

До выбора даты и времени карточки остаются нейтральными, а расписание выбранного помещения видно всегда.

## Бронирование

При создании брони пользователь указывает дату, время, количество участников, имя и цель посещения. Выбранные на главном экране дата и время автоматически подставляются в форму.

Одно помещение на выбранный период может иметь только одного ответственного. Один аккаунт не может создать несколько пересекающихся по времени броней. Количество участников не может превышать вместимость комнаты.

## Рейтинг и роли

У ученика начальный рейтинг равен 0. Завершённая бронь даёт +1 балл. Одна поздняя отмена в месяц бесплатна, а отмена более чем за 2 часа до начала не меняет рейтинг. Последующие поздние отмены уменьшают рейтинг на 2 балла.

Отрицательный рейтинг не блокирует аккаунт полностью: ученику может быть временно недоступна часть самых востребованных помещений. Для преподавателя рейтинговые ограничения не применяются.

В интерфейсе есть роли «Ученик» и «Преподаватель», раздел «Мои бронирования» с активной бронью и историей, а также раздел «Доп. информация» с краткими правилами сервиса.

## Интерфейс и технологии

Дизайн построен на основе проекта напарника и выдержан в едином стиле кампусного сервиса. Поддерживаются русский и английский языки, светлая и тёмная темы, адаптивная работа на компьютере и телефоне.

Frontend написан на React и TypeScript с использованием Vinext/Vite, Tailwind CSS, Base UI и Lucide Icons. На текущем этапе данные работают в демонстрационном режиме через `localStorage`; в дальнейшем этот слой заменяется backend API без изменения интерфейса.
